# Agent Rules

- Do not add external publishing, email, payment, or authentication side effects without explicit approval.
- Do not store secrets in repo.
- Keep AI automation human-in-the-loop; generated/suggested records must default to Pending Review.
- Public views must only expose Approved/Published records with Public visibility.
- Avoid home addresses or sensitive private locations in seed/demo data.
- Prefer small, verifiable feature slices with tests.
