# Milestones

## M1 Local MVP foundation
SQLite schema, seed data, public browse/search, entity profiles, relationship lists, graph page, submission form, admin queue.

## M2 Better moderation workflow
Admin edit screens, duplicate flags, status transitions, review notes, correction/removal requests.

## M3 Import/enrichment assistant
Paste URL/text -> draft records plus suggested relationships, always Pending Review with evidence.

## M4 Multi-ecosystem readiness
Ecosystem switcher, taxonomy editor, export/import, admin docs.

## M5 Deployable pilot
Auth, backups, deployment target, stakeholder onboarding docs.
