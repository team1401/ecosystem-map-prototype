# Source Proposal Summary

Source: `/Users/helix/.hermes/cache/documents/doc_cf00fce13960_Ecosystem_Mapping_Community_Asset_Discovery_Prototype_Proposal.docx`

Build target: Lean prototype for community asset discovery and relationship mapping.

Core MVP:
- Structured database with ecosystems, entities, events, resources, opportunities, needs, offers, relationships, submissions, contributors.
- Public submission flow with moderation.
- Admin review queue and editing/approval actions.
- Public searchable directory.
- Entity profile pages showing related records.
- Basic graph visualization.
- AI features deferred; suggestions/review fields included in schema.

Initial pilot assumptions:
- Pilot ecosystem can be selected later; seed data uses independent musicians as sample.
- Public records only show approved/published content.
- Private/admin-only records are hidden from public views.
